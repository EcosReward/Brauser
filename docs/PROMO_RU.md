# Brauser — лаборатория безопасности

## Короткое описание (для магазина / GitHub)

**Brauser** — десктопный браузер-лаборатория для проверки безопасности сайтов до регистрации и ввода данных. Откройте страницу, запустите аудит и получите понятный вердикт: безопасно, с осторожностью или не доверять.

## Слоган

- **Главный:** Проверяй сайт — потом доверяй.
- **Альтернативы:**
  - Браузер, который думает о безопасности за вас.
  - Лаборатория безопасности внутри обычного просмотра.
  - Увидел уязвимость — не отдал данные.

## Полное описание

Brauser совмещает привычный просмотр сайтов и встроенную лабораторию аудита. Вы гуляете по страницам своего сайта, собираете ссылки, запускаете полную проверку или отдельные модули — и сразу видите, что именно небезопасно.

Каждая находка объясняется простым языком: **где искать**, **какой путь закрыть**, **чем опасно** и **что сделать по шагам**. Уровень критичности помогает решить: регистрироваться на сайте или нет.

Подходит владельцам сайтов, админам, фрилансерам и всем, кто хочет быстро понять риски до передачи паролей и персональных данных.

## Ключевые возможности

- Встроенный Chromium-браузер с вкладками
- Вердикт безопасности и индекс доверия (0–100)
- Модули: движок/CMS, TLS, заголовки, cookie, XSS, SQL-инъекции, порты, админки, открытые файлы
- Понятные отчёты для новичков с точными URL/путями
- Сбор посещённых страниц и ссылок для XSS/SQL
- Изоляция отчётов по вкладкам
- Тёмный интерфейс лаборатории

## Кому подходит

- Владельцам сайтов перед запуском/релизом
- Тем, кто проверяет чужой/свой лендинг перед регистрацией пользователей
- Новичкам в безопасности, которым нужны простые объяснения

## Как пользоваться (30 секунд)

1. Откройте сайт во вкладке Brauser  
2. Погуляйте по разделам (или нажмите «Собрать ссылки»)  
3. Нажмите **Полная проверка безопасности**  
4. Смотрите вердикт и список находок справа  

## Запуск

```bash
npm install
npm start
```

## Важно

Активные проверки (XSS, SQL, порты, админки, файлы) отправляют тестовые запросы. Используйте только на сайтах, которыми владеете, или с явным разрешением.
